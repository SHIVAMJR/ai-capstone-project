\# AI Capstone Project — Development Instructions



\## Project Overview



This is my AI-assisted capstone project. The project will be developed incrementally with the help of AI coding tools.



\## Technology Stack



\- Node.js

\- JavaScript

\- React

\- Git

\- GitHub

\- Cursor / Claude Code



\## Coding Conventions



\- Use clear and descriptive variable and function names.

\- Prefer simple, readable, and maintainable code.

\- Use functional React components.

\- Keep components small and reusable.

\- Avoid unnecessary dependencies.

\- Handle errors appropriately.

\- Do not commit secrets, API keys, or environment variables.



\## Git Conventions



Use Conventional Commits.



Examples:



\- `feat: add user authentication`

\- `fix: resolve login validation`

\- `docs: update project documentation`

\- `chore: configure project`

\- `refactor: simplify API service`



\## AI-Assisted Development



When using an AI coding assistant:



1\. Understand the proposed changes before accepting them.

2\. Review generated code for correctness.

3\. Keep changes focused and minimal.

4\. Test changes before committing.

5\. Update documentation when necessary.
